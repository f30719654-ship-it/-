Updated: added auto-start option (start_enabled) in config/bed_aura.json. If start_enabled is true the mod will enable automatically on client start (you can still toggle with V).

How to use auto-start:
- config/bed_aura.json: set "start_enabled": true to enable auto mode at client start.
- The mod still requires cobblestone and a bed in your hotbar.

Build and install as before.
